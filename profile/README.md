# muneo

Put your AI coding subscriptions to work.

muneo brings your AI coding tools into one workspace.
See usage limits and reset windows, hand work to an available
agent, and review the changes before applying them.

- Track usage and choose your preferred agent order.
- Delegate coding tasks to an available agent.
- Find and address project improvements with Auto Fix.
- Connect your AI tools through MCP.

muneo is free. Use it with your existing AI service accounts.
